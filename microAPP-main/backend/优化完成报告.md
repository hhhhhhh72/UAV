## 🚀 快速开始

### 1. 运行配置脚本

```bash
# Windows
setup.bat

# Linux/Mac
./setup.sh
```

### 2. 编辑配置

编辑 `backend/.env`:

```env
JWT_SECRET=生成32位随机字符串
DSL_ADMIN_PASSWORD=你的密码
STUDY_ADMIN_PASSWORD=你的密码
```

### 3. 启动服务

```bash
cd backend
npm run dev    # 开发模式
npm start      # 生产模式
```

### 4. 查看日志

```bash
tail -f logs/$(date +%Y-%m-%d).log
```
