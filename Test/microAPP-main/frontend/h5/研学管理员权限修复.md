# 研学管理员权限修复报告

## 修复日期
2026-04-07

## 问题描述
研学管理员(`study_admin`)的后台管理中可以看到"飞手培训服务"(服务6)的相关配置,但实际上他们只能管理服务9(低空研学服务)。

## 修复内容

### 1. 侧边栏菜单修复 ✅

**文件**: `frontend/h5/src/views/admin/components/AdminSidebar.vue`

**修改**:
- 添加注释说明服务6(飞手培训)相关配置研学管理员不可见
- 侧边栏菜单中,"服务配置"对研学管理员可见,但实际只能看到服务9

**权限矩阵**:
```
服务6(飞手培训): admin ✓ | study_admin ✗
服务9(低空研学): admin ✓ | study_admin ✓
```

### 2. 服务配置页面修复 ✅

**文件**: `frontend/h5/src/views/admin/config/ServiceConfigList.vue`

**修改前**:
```javascript
{ title: '教育培训', ids: ['6', '9'], roles: ['admin', 'study_admin'] }
```

**修改后**:
```javascript
{ title: '研学教育', ids: ['9'], roles: ['admin', 'study_admin'] }
```

**效果**:
- 研学管理员登录后台后,**只能看到"低空研学服务"(服务9)的配置**
- **看不到"飞手培训服务"(服务6)**的配置入口
- 管理员(admin)仍然可以看到所有服务配置

## 权限隔离验证

**文件**: `backend/routes/admin.js`

1. **获取服务配置** (第281-304行):
```javascript
// 研学管理员只能看到服务9
if (req.user.role === 'study_admin') {
  return res.json({
    success: true,
    data: { '9': config['9'] }
  });
}
```

2. **更新服务配置** (第309-356行):
```javascript
// 研学管理员只能修改服务9
if (req.user.role === 'study_admin') {
  if (newConfig['9']) {
    servicesConfig['9'] = { ...servicesConfig['9'], ...newConfig['9'] };
  } else {
    return res.status(403).json({
      success: false,
      message: '无权修改此服务配置'
    });
  }
}
```

3. **订单管理** (第65-110行):
```javascript
// 根据角色过滤
if (req.user.role === 'study_admin') {
  applications = applications.filter(app => app.serviceId === '9');
}
```
