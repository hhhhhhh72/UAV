# 微信小程序开发规格

> 基于《无人机产业生态服务平台功能与作用方案》翻译,每个系统拆解为:用户故事→页面→API→组件

## 全局设计

### 导航结构

```
TabBar (4个):
  首页     → pages/index/index
  服务     → pages/services/services  
  消息     → pages/messages/messages
  我的     → pages/mine/mine
```

### 全局 Token

| 页面 | 路径 | 说明 |
|------|------|------|
| 配色 | 主色#1565C0 / 背景#FAFAFA / 卡片白 | 见design-system |
| 字体 | PingFang SC, 标题18px/正文15px/辅助13px | 微信默认 |
| 间距 | 8/12/16/24/32px 四级 | 统一内边距 |
| 空状态 | 每个列表页有空状态插图+引导文案 | 全局组件 |
| 加载 | 骨架屏(列表)/loading spinner(按钮) | 全局组件 |

## ① 会员生态资源管控

### 用户故事
1. 企业用户注册时选择产业分类(整机/零部件/飞控/载荷/运营商/实训院校)
2. 浏览专家智库,按领域筛选(低空管控/适航/研发/应急/政策/投融资)
3. 查看产业资源台账(无人机/机场/试飞场地/测试基地),费用+预约方式
4. 协会管理员管理7级权限(会长→访客)
