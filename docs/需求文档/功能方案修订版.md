# 低空经济生态服务平台【软件系统】功能与作用方案（修订版 v2）

> **修订说明**：本修订版以《功能与作用方案》（2026-07）为底稿，按《功能方案评审》（2026-08-04）逐条落地。核心变更：① 每个功能划定唯一权威归属（确需跨系统引用的注明「入口承接」）；② 新增统一业务类型术语标准；③ 补齐商业化设计、MVP 分期与运营机制；④ 移除与定位不符的「行业舆情研判」。修订对照表见文末附录。

---

## 定位说明

区别于政府空域监管平台（九天航驭 / 低空智能管服平台）。

本平台是**行业协会运营、面向 180 余家会员单位、市场化产业生态服务载体**，不承担官方飞行监管职能。

**核心定位**：资源连接器、供需撮合器、产业服务窗口、产学研转化枢纽、行业合规服务中心。

**业务类型统一术语标准**（本修订版新增，全平台唯一标准）：

| 业务类型 | 定义 | 关联分类 |
|---|---|---|
| 整机 / 零部件 | 无人机设备与配件 | 产业分类·设备制造 |
| 航拍服务 / 检测标定 / 空域协调 / 试飞测试 | 供给能力（会员上架） | 产业分类·运营服务 |
| 培训课程 | 课程超市（平台运营） | 产业分类·实训院校 |
| 需求（巡检/测绘/应急/植保/文旅/采购/技术开发） | 需求大厅（发单侧） | 与供给类型按业务域映射 |

> 落地约定：需求类型与供给类型按业务域映射（如「巡检需求 ↔ 巡检无人机/航拍服务」），平台所有模块引用本标准，不再各立枚举。

## 一、会员生态资源总库系统（基础底座）

### 具体功能

1. **会员单位数字化档案库**：分类录入整机、零部件、飞控、载荷、运营服务、实训院校、通航机场、检测机构；标签化标注企业核心产品、技术优势、可提供服务、业务需求。
2. **专家智库数据库**：入库低空管控、适航、无人机研发、应急救援、法务政策、投融资专家。
3. **场地资源台账**（**唯一权威归属**）：归集大安机场、龙兴机场、各类试飞场地、中试基地、起降点资源信息、空域条件、使用费用、预约方式。
4. **人才资源库**：飞手、运维工程师、低空技术人才、院校毕业生信息。
5. **多级权限管理**：协会管理员、副会长单位、普通会员、合作院校、政府访客分级浏览。

### 平台作用

1. 解决协会现有资源信息分散、线下台账难以共享的痛点；
2. 对外展示重庆低空全产业链版图，作为政府招商、项目对接数字化名片；
3. 为后续供需智能匹配提供底层数据支撑；
4. 支撑协会常态化资源统筹，避免会员信息孤岛。

## 二、产业链供需智能撮合子系统（核心商业化功能）

### 具体功能

1. **需求发布大厅**：政府项目、巡检、测绘、应急、农林植保、低空文旅、设备采购、技术开发需求在线发布；支持政企需求定向推送会员。
2. **供给能力展示大厅**：会员上架**无人机整机、零部件、航拍服务、试飞测试、检测标定、空域协调服务**六类供给。
   > 修订：删除「培训」（**入口承接至五·培训课程超市**，避免双入口）；试飞测试供给仅作展示卡片，台账与预约见一·3 / 三·3。
3. **智能匹配算法**：根据需求关键词、地域、赛道自动推荐对应会员企业。
4. **项目对接闭环**：线上洽谈、方案交换、合作意向登记、项目落地结果反馈。
5. **场景资源集市**：赛事活动资源、无人机航拍团队资源池。
   > 修订：删除「应急救援资源调度库」（**入口承接至七·低空应急协同**）。

### 平台作用

1. 打通"有项目找不到服务商、有企业找不到订单"行业痛点；
2. 协会由单纯组织活动转变为持续数字化撮合，持续创造会员价值；
3. 归集全市低空应用场景需求，推动会员参与城市治理、水利、应急等项目；
4. 建立产业交易台账，为行业报告、产业政策申报提供数据依据。

## 三、产学研用协同创新子系统（技术转化板块）

### 具体功能

1. **技术成果库**：汇集高校、研究院、会员企业专利、创新技术、样机方案。
2. **技术需求征集**：企业研发难题、技术攻关需求线上征集。
3. **中试基地资源预约入口**（**预约唯一入口**）：对接全市各试飞基地、检测实验室，线上预约场地、测试服务；台账数据读取一·3，供给展示卡片读取二·2。
4. **课题联合攻关通道**：协会发起联合研发项目线上征集参与单位。
5. **成果转化跟踪**：技术落地、样机测试、产业化进度线上登记。

### 平台作用

1. 针对性解决明月湖等科研平台"成果转化难、自我造血弱"痛点；
2. 避免各地盲目重复建设中试基地，推动测试场地共建共享；
3. 搭建企业与海联职院、各大研究院常态化线上对接通道；
4. 培育新技术、新产品，助力重庆低空创新链与产业链融合。

## 四、合规与政策服务子系统（行业刚需）

### 具体功能

1. **政策资讯中心**：低空经济、无人机法规、空域管理、补贴政策、行业标准实时更新；区分通用航空、无人机新业态，厘清两类业态政策边界。
2. **合规知识库**：无人机实名登记、飞行报备流程、企业运营资质、适航指南、"黑飞"风险警示。
3. **团体标准管理**：协会牵头制定的低空、无人机团体标准线上查阅、意见征集。
4. **政策申报服务窗口**：产业补贴、产教融合项目、专精特新申报指南、材料辅导入口。
5. **企业案例库**（本修订版补入）：收录会员企业应用案例与最佳实践，支撑品牌展示与招商洽谈。
   > 修订：删除「行业舆情研判」——与"市场化产业服务载体"定位不符，近似政府舆情职能，会员价值低频且维护成本高。如协会确有舆情需求，另行以人工简报形式提供，不纳入平台功能。

### 平台作用

1. 提升会员合规意识，降低企业飞行、经营法律风险；
2. 向行业持续传递科学认知：不把通用航空事故等同于低空经济系统性风险；
3. 作为协会向政府反馈行业诉求线上通道，收集企业发展堵点；
4. 标准化输出政策服务，减轻协会日常咨询工作量。

## 五、人才培育与产教融合子系统

### 具体功能

1. **低空人才需求发布**：企业发布招聘、实习岗位。
2. **院校成果展示**：例如：海联职业学院等合作院校专业设置、实训能力、毕业生资源。
3. **培训课程超市**（**培训唯一权威归属**）：无人机驾驶员考证、低空运维、应急无人机应用系列课程；课程报名、付费、证书发放全流程闭环。
   > 修订：系统二供给大厅「培训」入口承接至此，全平台仅此一处承担培训业务。
4. **赛事管理模块**：无人机技能竞赛、创新大赛报名、成果展示。
5. **校企共建**：订单班、实训基地意向对接通道。
   > 边界：院校科研合作（研究院对接）归三；院校人才培养（校企共建）归五；同一院校两线并存时在档案中分域标注。

### 平台作用

1. 补齐低空产业人才缺口，构建"院校培养+企业用工"闭环；
2. 落地协会产教融合战略，持续深化和重庆高职院校合作；
3. 打造重庆低空人才数字化蓄水池，支撑产业长期发展。

## 六、活动与品牌服务子系统

### 具体功能

1. **协会活动线上入口**：产业论坛、走访交流、企业沙龙、外出考察报名。
2. **会员宣传展示专区**：企业宣传片、案例、产品展示。
3. **行业展会统一组团报名**、成果线上预展示。
4. **行业白皮书、产业调研报告线上发布**。

### 平台作用

1. 线上线下联动，放大协会活动影响力；
2. 为中小会员提供低成本品牌曝光渠道；
3. 持续塑造重庆无人机产业协会行业影响力。

---

## 七、低空应急资源协同调度子系统（特色亮点）

### 具体功能

1. **会员无人机应急队伍、装备清单、作业能力线上建档**（**应急唯一权威归属**）。
   > 修订：系统二「场景资源集市」不再承载应急调度；平台应急调度功能全部由本系统承担。
2. **水灾、山火等突发事件资源快速检索、联络调度**。
3. **应急救援案例库**：沉淀民间无人机救援实战经验。
4. **应急演练招募、协同方案线上沟通**。

### 平台作用

落地"人民至上、生命至上"，发挥民间无人机力量在抢险救灾价值；打造重庆特色低空应急协同体系，成为政府应急体系重要补充。

## 八、商业化设计（本修订版新增）

> 平台定位「核心商业化功能」，需明确商业模式。以下为建议方向，具体费率与政策由协会确认后固化。

1. **会员基础服务（免费）**：档案、供需浏览、政策资讯、活动报名——服务 180 家会员的底座。
2. **撮合服务费（核心）**：供需对接成功（合同/订单落地）后按比例收取撮合服务费；协会可对会员实施费率折扣。
3. **增值服务（按需）**：专家咨询、合规辅导、申报代报、人才招聘置顶、品牌展示加权。
4. **数据服务（远期）**：产业报告、交易台账脱敏数据向政府/科研机构授权输出。
5. **资金安全**：涉及线上交易（培训付费、合同担保）的，一律经平台资金托管账户，保障双方权益。

## 九、MVP 分期建议（本修订版新增）

> 面向 180 家会员，建议分三期建设，每期交付可独立运营。

| 期次 | 范围 | 目标 |
|---|---|---|
| **一期（3 个月）** | 会员档案 + 需求大厅 + 供给展示 + 智能匹配 + 政策资讯 | 跑通"会员 → 供需 → 撮合"主链路，平台上线运营 |
| **二期（3 个月）** | 项目对接闭环 + 培训课程超市（含付费托管）+ 赛事活动 + 品牌展示 | 商业化闭环落地，产生首批撮合与营收 |
| **三期（3 个月）** | 产学研转化 + 合规申报 + 应急协同 + 数据报告 | 全场景覆盖，形成行业数据底座 |

## 平台整体核心价值总结

1. **资源数字化**：整合协会 180 家会员分散资源，形成统一产业数字底座；
2. **供需常态化**：由"阶段性线下活动"升级为 7×24 小时持续撮合，持续为会员创造业务机会；
3. **创新链条化**：打通科研、中试、产业化，缓解科研成果落地难，规避重复建设；
4. **服务标准化**：政策、合规、人才、空域、场地服务线上化，降低企业获取资源成本；
5. **政企桥梁数字化**：汇集行业诉求，形成数据支撑，辅助政府科学制定低空产业政策；
6. **生态协同化**：推动制造、运营、科研、院校、通航场地多方协同，构建重庆低空经济良性产业生态。

---

## 重要边界说明（汇报务必加上，规避职能冲突）

本生态服务平台不替代政府官方低空监管平台，不开展飞行计划审批、空域管控等行政执法职能；定位为产业服务、资源协同、市场撮合的行业第三方平台，与市级低空智能管服平台形成互补，构建"政府监管+协会生态服务"双轮体系。
