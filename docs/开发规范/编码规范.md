# 编码规范

## 分层约束（铁律）

```
Handler  → 只做: 解析请求、调 Service、调 respond/fail
            禁做: SQL查询 | 业务规则判断 | 直接读写库

Service  → 只做: 角色校验 | 归属校验 | 状态机迁移 | 调 Repository接口
            禁做: http.Request | ResponseWriter | JSON编解码 | 环境变量

Repository → 只做: SQL执行 | 数据映射 | 返回Domain对象
              禁做: 业务规则 | 权限判断 | HTTP相关
```

## 命名约定

| 层 | 约定 | 示例 |
|------|------|------|
| 路由 | `/api/v1/资源复数` | `/api/v1/demands` |
| Handler | `func (s *Server) verbNoun(...)` | `createDemand` |
| Service | `type NounService struct` | `DemandService` |
| Repository接口 | `type NounRepository interface` | `DemandRepository` |
| PG实现 | `type nounRepo struct` (小写开头) | `demandRepo` |
| 迁移 | `00000X_description.up.sql` | `000001_init.up.sql` |

## 响应规范

```go
respond(w, r, statusCode, data)              // 成功
paginatedRespond(w, r, items, totalCount)    // 分页
fail(w, r, statusCode, err)                  // 失败
```

## 验收标准

```bash
go build ./...     # 编译通过
go vet ./...       # 零告警
go test ./internal/...  # 全部 PASS
```

## KISS原则

- 小文件: 200-400行典型, 800行上限
- 小函数: <50行
- 浅嵌套: <4层, 用 early return
- 可变性: 创建新对象, 不原地修改
