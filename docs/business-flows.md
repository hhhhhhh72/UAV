# 无人机产业综合服务平台 — 业务流程文档

> 本文档面向业务讨论，不含代码细节。每个模块说明**什么人、干什么、结果如何**。

---

## 平台角色

| 角色 | 谁 | 能做什么 |
|------|------|------|
| 个人用户 | 飞手、求职者、买家 | 接单、竞标、求职、购买、发帖 |
| 企业用户 | 无人机公司、培训机构 | 发布需求、招聘、卖产品、签合同 |
| 协会管理员 | 行业协会工作人员 | 审核企业入驻、管理内容、查看数据 |
| 平台管理员 | 平台运营方 | 全部管理权限、数据导出、用户管理 |

## 1. 用户认证

**一句话**：微信扫码登录，不用注册账号。

**流程**：
```
用户打开小程序 → 点微信登录 → 授权手机号 → 进入首页
                                         ↓
                              后台自动创建用户记录
                              生成15分钟有效令牌
```

**用到的接口**（共5个）：微信登录、令牌刷新、安全登出、查个人信息、修改个人信息

## 2. 企业入驻

**一句话**：无人机公司提交资质 → 协会审核通过 → 获得接单和发单资格。

**流程**：
```
企业用户                    协会管理员
  │                            │
  │ 填写企业资料                │
  │ （名称/开户账号/营业执照）    │
  │          ↓                  │
  │     提交审核                 │
  │          ↓                  │
  │                            │ 查看待审核列表
  │                            │       ↓
  │                     通过 ← │ → 驳回（需填原因）
  │                     补件 ← │ → 要求补充材料
  │          ↓                  │
  │   [通过] 企业获得全部权限     │
  │   [驳回] 查看原因后可重新提交  │
  │   [补件] 补充材料后再提交     │
```

**企业状态变化**：草稿 → 已提交 → 已通过 / 已驳回 / 需补件

**已完成的额外能力**：
- 按名称搜索企业
- 批量选择企业一键审批（最多50家/批）
- 列表自动隐藏手机号中间四位

## 3. 需求大厅（核心业务流程）

**一句话**：企业发布无人机作业需求 → 飞手竞标报价 → 企业选中最优报价 → 双方确认完成 → 资金结算。

### 3.1 发布需求
```
企业用户
  │
  │ 填写需求表单
  │ （标题/业务类型/预算/描述/图片/联系方式）
  │          ↓
  │     提交发布
  │          ↓
  │   管理员审核通过 → 公开发布到需求大厅
```

**6种业务类型**：电缆巡检 / 植保运输 / 喷洒农药 / 清洗喷绘 / 买卖租赁 / 其他

### 3.2 竞标报价
```
飞手（个人/企业）           需求大厅
  │                            │
  │ 浏览需求列表                │
  │ （按类型筛选/按预算排序）     │
  │          ↓                  │
  │ 点开某个需求                │
  │          ↓                  │
  │ 填写报价金额 + 方案说明      │
  │          ↓                  │
  │     提交竞标       ─────→   │ 报价记录持久化保存
```

**约束**：不能投自己的需求、需求必须是"已发布"状态才能投

### 3.3 选中中标（核心交易节点）
```
企业（需求发布者）
  │
  │ 查看收到的所有报价
  │ （比较价格和方案）
  │          ↓
  │ 选中一个报价 → "就选这家"
  │          ↓
  │   系统原子锁定：
  │   需求状态 → 已匹配
  │   被选中的报价 → 已接受
  │   其他报价 → 保持待选
```

**并发安全保障**：如果两个人同时点"选中"，系统保证只有一个人能成功，不会出现一个需求被两个人同时中标。

### 3.4 双确认完成
```
企业                          飞手
  │                            │
  │ 点"确认完成"                │ 点"确认完成"
  │          ↓                  │          ↓
  │        双方都确认了 → 需求完成
```

### 3.5 争议处理
```
任何一方对结果不满意
  │
  │ 发起争议
  │ （只有需求发布者可以发起）
  │          ↓
  │  需求回到"已发布"状态，可重新选择
```

**需求状态变化**：待审核 → 已发布 → 已匹配 → 已完成（可被已取消/已驳回旁路终止）

**用到的接口**（共11个）：创建需求、需求列表、修改需求、提交审核、管理员审核/通过、创建报价、选中报价、双确认完成、发起争议

## 4. 招聘求职

**一句话**：企业发职位 → 求职者投简历 → 企业筛选面试录用。

**流程**：
```
企业                          求职者
  │                            │
  │ 发布职位                    │ 创建简历
  │ （名称/薪资/地点/要求）      │ （自我介绍/经历/技能）
  │          ↓                  │          ↓
  │ 公开发布                    │
  │          ↓                  │
  │                            │ 浏览职位 → 投递
  │          ↓                  │
  │ 收到投递列表                │
  │          ↓                  │
  │ 查看简历 → 约面试 → 录用     │ 或拒绝/撤回
```

**职位状态**：草稿 → 已发布 → 已关闭 → 归档
**投递状态**：已投递 → 已查看 → 面试中 → 已录用 / 已拒绝 / 已撤回

```
  │ 其他人评论互动               │
  │          ↓                  │
  │ 可举报不良内容    ─────────→ │ 处理举报
```

## 7. 用工派遣

**一句话**：企业发布临时用工需求 → 劳务方报价竞标 → 雇主分配人员。

**流程**：
```
雇主                          劳务方
  │                            │
  │ 发布用工需求                │ 浏览可接的用工订单
  │ （岗位/人数/日期/预算）      │          ↓
  │          ↓                  │ 提交报价（金额+方案）
  │                            │          ↓
  │ 收到报价列表                │
  │          ↓                  │
  │ 选择报价 → 分配人员          │
```

**状态变化**：草稿 → 已提交 → 已报价 → 已确认 → 已完成 → 已结算（可取消）

## 8. 合同签约

**一句话**：选择合同模板 → 创建合同 → 签章平台在线签署 → 状态自动回调更新。

**流程**：
```
企业用户                    外部签章平台
  │                            │
  │ 选择合同模板                │
  │          ↓                  │
  │ 创建合同（草稿）            │
  │          ↓                  │
  │ 发起签署                   │
  │          ↓                  │
  │                            │ 双方在线签署
  │                            │          ↓
  │                            │ 签署完成后自动回调通知
  │                            │ （签名验证 + 防重复处理）
  │          ↓                  │
  │ 合同状态自动更新为"已签署"   │
  │          ↓                  │
  │ 如需作废 → 点作废           │
  │ （只能作废自己的合同）       │
```

**状态变化**：草稿 → 已发送 → 签署中 → 已签署 → 已作废 / 已过期

```
  │          ↓                  │
```

## 13. 资金托管

**一句话**：第三方资金存管，保护交易双方——充值→冻结→完成→释放或退款。

**流程**：
```
用户
  │
  │ 查看账户余额（可用金额 + 冻结金额）
  │
  │ ┌─ 充值：把钱充到平台账户
  │ │
  │ ├─ 冻结：交易进行中，平台暂时锁定这笔钱
  │ │          （保证卖家能收到钱、买家不满意能退款）
  │ │
  │ ├─ 释放：交易顺利完成，冻结的钱解冻给卖家
  │ │
  │ └─ 退款：交易取消或争议，冻结的钱退还给买家
  │
  │ 查看全部交易流水记录
```

**四种操作类型**：充值 / 冻结 / 释放 / 退款

## 17. 管理后台（Web端）

协会和平台管理员使用的电脑端后台，与手机小程序数据互通：

### 数据看板
- 顶部4个指标卡片：总需求数、待审核企业数、帖子数、待处理举报数
- 趋势图：近14天需求增长曲线
- 饼图：需求类型分布 + 需求状态分布
- 服务状态：存储后端类型、限流配置

### 企业审核
- 审核列表（待审核/已通过/已驳回/全部筛选）
- 每行展示：企业名称、开户账号、状态标签、提交时间
- 操作按钮：通过（绿色）/ 驳回（红色，需填原因）/ 补件

### 其他管理功能
- 需求管理：查看所有需求，审核通过/驳回
- 举报管理：查看用户举报
- 行业资讯：发布和编辑文章
- 评价审核：审核评价内容
- 用户管理：查看用户/新建/修改角色
- 服务配置：Banner轮播图管理、公告编辑
- 数据导出：需求数据和企业数据CSV导出（Excel可直接打开）
- Token工具：生成不同角色的测试令牌

## 全局能力

| 能力 | 说明 |
|------|------|
| 身份鉴权 | 微信登录 + 令牌15分钟过期 + 4级权限控制 |
| 流量控制 | 每秒100次请求上限，防止刷接口 |
| 防重复提交 | 同一操作24小时内去重，网络重试不会创建重复数据 |
| 操作记录 | 所有写操作记录操作人、时间、对象、结果，全程可追溯 |
| 数据加密 | 手机号、身份证号、信用代码加密存储，公开接口自动脱敏 |
| 双重存储 | 本地开发用内存、生产环境用PostgreSQL，切换只需一个环境变量 |
| 容器部署 | Docker一键启动，PostgreSQL+应用双容器自动编排 |
| 自动测试 | 76个测试用例覆盖全部业务场景，含并发压力和极限测试 |
