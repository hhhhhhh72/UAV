# 架构总览

## 分层架构（铁律）

```
Handler  → 解析请求 / 调Service / respond或fail
            禁做: SQL查询 / 业务判断 / 直接读写库

Service  → 角色校验 / 状态机 / 调Repository接口
            禁做: http.Request / ResponseWriter / JSON编解码

Repository → SQL执行 / 数据映射 / 返回Domain对象
             禁做: 业务规则 / 权限判断 / HTTP相关
```

## 项目结构

```
cmd/api/main.go           启动入口,组装依赖
internal/
  httpapi/                路由/中间件/Handler
  service/                业务规则/状态机
  repository/             接口定义+PG/内存双实现
  domain/                 业务实体(70+ struct)
  config/                 集中配置
  logger/                 结构化日志(slog)
  cache/                  内存TTL缓存
  middleware/              输入消毒
  crypto/                 AES-256-GCM
migrations/               17组迁移(up/down, 80表)
```

## 中间件链

```
请求 → 幂等去重(24h) → 限流(100/s) → 链路追踪 → Panic恢复 → 安全头 → CORS → Token鉴权 → 业务
```

## 双存储模式

| 环境 | 存储 | 触发条件 |
|------|------|------|
| 开发 | 内存 | `DATABASE_URL` 未设置 |
| 生产 | PostgreSQL | `DATABASE_URL` 已设置 |
