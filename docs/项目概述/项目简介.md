# 项目简介

面向无人机产业链的全栈服务平台。微信小程序供飞手/企业使用，Web管理后台供协会管理员使用。

**180+** 会员单位 | **212条** API端点 | **66张** 数据表 | **7大** 业务系统

## 核心业务流程

企业发布无人机作业需求 → 飞手竞标报价 → 发布者选中中标者 → 双方确认成交 → 资金托管结算。

## 平台定位

产业服务 + 资源协同 + 供需对接 + 产业赋能。与政府低空智能管控平台形成"政府管控 + 协会生态"双轮驱动。

## 技术栈

| 层 | 技术 |
|------|------|
| 后端 API | Go 1.22+, 标准库 net/http |
| 数据库 | PostgreSQL 15+(生产) / 内存存储(开发) |
| 部署 | Docker + docker-compose |
| CI/CD | GitHub Actions |
| 小程序 | 微信原生 + Vant Weapp |

## 7大业务系统

| 系统 | 说明 |
|------|------|
| 会员生态资源管控 | 会员数字化/专家智库/资源台账/多级权限 |
| 产业供需智能对接 | 需求发布/供应展示/智能匹配/项目闭环 |
| 产学研协同创新 | 科技成果库/研发难题/课题攻关/成果转化 |
| 合规政策服务 | 政策资讯/合规知识库/团体标准/项目申报 |
| 人才教育与产教融合 | 培训认证/赛事管理/招聘求职/校企共建 |
| 活动与品牌服务 | 活动管理/会员品牌/展会排期/行业报告 |
| 低空应急资源协同 | 应急资源/一键调度/救援案例/部门对接 |
