# 快速开始

## 环境要求

- Go 1.22+
- PostgreSQL 15+ (可选，不设则用内存存储)
- Git

## 本地开发

```bash
# 1. 设置密钥
set AUTH_SECRET=至少32字节的随机字符串
set ADMIN_DEV_MODE=true

# 2. 启动服务
go run ./cmd/api

# 3. 验证
curl http://localhost:8080/healthz
```

## 运行测试

```bash
go test ./internal/...           # 全量单元测试
bash Test/e2e.sh                 # 端到端接口测试
```

## 代码质量

```bash
go build ./...   # 编译
go vet ./...     # 静态分析
```

## Docker 部署

```bash
docker-compose up -d    # PG + API 双容器
```

## 环境变量

| 变量 | 必填 | 说明 |
|------|:--:|------|
| `AUTH_SECRET` | ✅ | JWT 签名密钥,至少32字节 |
| `DATABASE_URL` | — | PG连接串,不设用内存 |
| `ADMIN_DEV_MODE` | — | `true`开启开发令牌 |
| `WECHAT_APPID` | — | 小程序AppID |
| `WECHAT_APPSECRET` | — | 小程序AppSecret |
| `ENCRYPTION_KEY` | — | AES-256-GCM密钥 |
| `CORS_ORIGINS` | — | 跨域来源,逗号分隔 |
| `HTTP_ADDR` | — | 监听地址,默认`:8080` |
| `LOG_DIR` | — | 日志目录,默认`./logs` |
