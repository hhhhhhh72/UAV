## 3. 架构审计

### 3.1 分层架构

```
请求 → 幂等去重(24h) → 限流(100/s) → 链路追踪 → Panic恢复 → 安全头 → CORS → Token鉴权 → 业务处理
```

**评分：✅ 优秀**

- Handler → Service → Repository 三层分离清晰
- 每层职责明确（见 CLAUDE.md 铁律）
- 中间件链完整

### 3.2 双存储模式

| 模式 | 触发条件 | 用途 |
|------|------|------|
| PostgreSQL | `DATABASE_URL` 已设置 | 生产环境 |
| 内存 | `DATABASE_URL` 未设置 | 开发/演示 |

**评分：✅ 优秀** — 极大降低开发门槛

### 3.3 Token 认证

- 自定义 HMAC-SHA256 Bearer Token（非 JWT）
- Access Token 15 分钟 + Refresh Token 7 天（轮转刷新）
- 微信 code2Session 自动登录
- 4 级 RBAC + 协会 7 级细分

**评分：✅ 良好** — 功能完整，但非标准 JWT 可能影响第三方集成
