## 二、零冲突核心原则

| # | 规则 | 违反后果 |
|---|---|---|
| **1** | **每人只能编辑自己分配的文件目录**，绝不动别人的文件 | Merge Conflict，阻塞所有人 |
| **2** | **共享组件/布局冻结** — `components/`、`pages.json`、`utils/`、`App.vue` 如需修改，必须群内同步后由 A 统一操作 | 全局崩塌 |
| **3** | **先 Pull 再 Push** — 每次开始工作前 `git pull --rebase`，结束立即 PR | 分叉累积 |
| **4** | **🚨 禁止擅自推送 GitHub** — 任何人 push 前必须经 A 书面确认。AI 辅助代码必须人工审核后再 push | 不可逆的远程代码污染 |
