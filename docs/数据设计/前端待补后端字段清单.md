## 三、JSONB 写入约束（重要踩坑）

`pgx v5` 将 **nil slice 编码为 SQL NULL**，会违反 `NOT NULL DEFAULT '[]'` 约束
（报错 `violates not-null constraint (SQLSTATE 23502)`）。
已修复：postgres 包新增 `jsonbSlice[T]` 泛型 helper，
`courseRepo` / `compRepo` / `pgCollegeRepo` 的 Create/Update 统一归一化 nil → 空数组。
