# 业务系统总览

平台按重庆市无人机产业协会需求,划分为7大业务系统,覆盖30+子模块。

## 系统对照

| 系统 | 核心子模块 | 对应表数 |
|------|------|:--:|
| ①会员生态资源管控 | 会员注册/专家智库/产业资源台账/人才资源库/协会7级权限 | 12 |
| ②产业供需智能对接 | 需求大厅/供应展示/竞标报价/智能匹配/资源池 | 6 |
| ③产学研协同创新 | 科技成果库/研发难题广场/课题攻关/测试预约/成果转化追踪 | 8 |
| ④合规政策服务 | 政策资讯/合规知识库/团体标准库/项目申报/企业案例库 | 5 |
| ⑤人才教育与产教融合 | 培训认证/赛事管理/招聘求职/院校展示/校企共建 | 10 |
| ⑥活动与品牌服务 | 活动管理/会员品牌展示/展会排期/行业报告发布 | 6 |
| ⑦低空应急资源协同 | 应急资源/一键调度/救援案例库/部门对接/联合演练 | 5 |

| 模块 | 说明 |
|------|------|

| 二手交易 | 商品发布/收藏 |

| 管理后台 | 数据看板/CSV导出/批量审核 |
