# 产业供需智能对接

## 子模块

### 需求发布大厅（信息公告模式）
作业项目/巡检/测绘/应急/农林植保/低空物流/设备采购。
发布后进入**待审核**，管理员审批通过后公开（含完整联系方式，可直接电话联系）。

### 需求流程
发布 → 待审核（管理员审批）→ 公开 / 驳回（可修改后重新提交）/ 取消
公开后：发布者可标记完成 / 取消。
API: `POST /api/v1/demands` → `GET /api/v1/demands` → `GET /api/v1/demands/{id}`
`POST /api/v1/admin/demands/{id}/review`（审批）→ `POST /api/v1/demands/{id}/complete`（完成）→ `POST /api/v1/demands/{id}/cancel`（取消）

> 竞标流程（发布→竞标→选中→双确认）为二期规划，代码已移除，`demand_bids` 表保留历史数据。

### 智能匹配
基于关键词+业务类型+地理位置的评分推荐,支持搜索+匹配组合。
API: `GET /api/v1/recommendations`, `GET /api/v1/match`

### 产业资源池
应急调度库/大型活动资源池/飞行团队资源池。
API: `GET /api/v1/resource-pools`
