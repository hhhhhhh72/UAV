# 产业供需智能对接

## 子模块

### 需求发布大厅
作业项目/巡检/测绘/应急/农林植保/低空物流/设备采购。
API: `POST /api/v1/demands` → `GET /api/v1/demands`

### 竞标流程
创建需求→提交审核→管理员审批→飞手竞标→发布者选中中标→双确认完成→争议处理。
API: `POST /api/v1/demands/{id}/applications` → `POST /api/v1/demands/{id}/applications/{appId}/select`

### 智能匹配
基于关键词+业务类型+地理位置的评分推荐,支持搜索+匹配组合。
API: `GET /api/v1/recommendations`, `GET /api/v1/match`

### 产业资源池
应急调度库/大型活动资源池/飞行团队资源池。
API: `GET /api/v1/resource-pools`
