# 活动与品牌服务

## 子模块

### 活动管理
产业论坛/走访交流/行业沙龙,在线报名。
API: `GET /api/v1/events`, `POST /api/v1/events/{id}/register`

### 会员品牌展示
企业名片/产品展示/荣誉资质。
API: `GET /api/v1/portfolios`, `GET /api/v1/portfolios/mine`

### 展会排期
产业展会统一排期,展位申请与审核。
API: `GET /api/v1/exhibitions`, `POST /api/v1/exhibitions/{id}/booths`

### 行业报告
白皮书/调研报告在线发布。
API: `GET /api/v1/industry-reports`
