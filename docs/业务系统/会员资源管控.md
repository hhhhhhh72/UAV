# 会员生态资源管控

## 子模块

### 会员数字化建档
按无人机产业链分类注册:整机/零部件/飞控/载荷/运营商/实训院校。
企业注册→提交审核→管理员审批(通过/驳回/补件)→批量审批(最多50条/批)。

### 专家智库
覆盖领域:低空管控/适航认证/无人机研发/应急救援/政策法规/投融资。
API: `GET/POST /api/v1/admin/experts`

### 产业资源台账
无人机/无人机机场/试飞场地/测试基地等资源信息,含使用费用和预约方式。
API: `GET /api/v1/industry-resources`, `POST /api/v1/admin/industry-resources`

### 人才资源库
飞手/维修工程师/无人机产业人才/院校毕业生信息。
API: `GET /api/v1/certified-pilots`
