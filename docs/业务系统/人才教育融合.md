# 人才教育与产教融合

## 子模块

### 培训认证
CAAC/大疆UTC/人社等级证书管理,培训课程发布与报名,教练飞手认证。
API: `GET /api/v1/certificates`, `GET /api/v1/training-courses`, `POST /api/v1/admin/certificates/{id}/approve`

### 付费报名
课程冻结资金→完成培训→释放资金+自动发证。
API: `POST /api/v1/training-courses/{id}/pay-and-enroll`

### 赛事管理
无人机竞技/创新创业大赛,在线报名参赛。
API: `GET /api/v1/competitions`, `POST /api/v1/competitions/{id}/register`

### 招聘求职
职位发布/简历管理/投递→面试→录用。
API: `GET /api/v1/jobs`, `POST /api/v1/resumes`, `POST /api/v1/applications`

### 院校展示
高职院校无人机专业设置/实训条件/毕业生资源。
API: `GET /api/v1/colleges`

### 校企共建
定向培养/实训基地/联合实验室。
API: `GET /api/v1/cooperation-programs`
