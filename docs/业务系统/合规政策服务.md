# 合规政策服务

## 子模块

### 政策资讯中心
无人机产业/无人机法规/民航局政策实时更新,区分通用航空与无人机新业态政策边界。
API: `GET /api/v1/articles`

### 合规知识库
无人机实名登记/飞行报备/商业运营资质/适航指南/禁飞区。
API: `GET /api/v1/compliance-docs`

### 团体标准库
协会制定的低空/无人机团体标准在线查阅下载。
API: `GET /api/v1/compliance-standards`

### 项目申报窗口
企业资质申请/政府补贴/专项资金申报。
API: `GET /api/v1/project-applications/mine`, `POST /api/v1/admin/project-applications/{id}/review`

### 企业案例库
汇集事故/事故征候/最佳实践,提供风险应对参考。
API: `GET /api/v1/cases`
