# 低空应急资源协同

## 子模块

### 应急资源建档
无人机应急装备清单、作业能力在线注册。
API: `GET /api/v1/emergency-resources`, `POST /api/v1/admin/emergency-resources`

### 调度记录
突发事件资源调度全过程记录。
API: `GET /api/v1/emergency-dispatches`, `POST /api/v1/admin/emergency-dispatches`

### 救援案例库
山火/洪水/地震/搜救——全球无人机救援实战案例和经验教训。
API: `GET /api/v1/rescue-cases`

### 部门对接
消防/公安/应急局联动协议管理,联合演练记录。
API: `GET /api/v1/emergency-depts`, `GET /api/v1/emergency-drills`
