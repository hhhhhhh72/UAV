# 产学研协同创新

## 子模块

### 科技成果库
汇集高校/科研院所/企业专利、新技术、新产品。
API: `GET /api/v1/achievements`

### 企业研发难题广场
技术瓶颈公开发布,揭榜挂帅。
API: `GET /api/v1/rd-challenges`

### 课题联合攻关
协会发布协同研发项目,招募参与单位。
API: `GET /api/v1/research-projects`

### 测试环境预约
对接试飞基地/资质实验室,在线预约场地和测试服务。
API: `GET /api/v1/test-sites`, `POST /api/v1/test-sites/{id}/book`

### 成果转化追踪
实验室→中试→产业化→上市,全流程里程碑管理。
API: `POST /api/v1/transformations/{id}/advance`, `POST /api/v1/transformations/{id}/milestones`
